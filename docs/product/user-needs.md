# Whaddo? — User Needs

**Status:** Draft — Not yet validated with users

## UN-01 — Find Suitable Activities
Users need to identify activities that fit their available time and current circumstances.

## UN-02 — Discover New Activities
Users need to explore activities they have not previously considered.

## UN-03 — Make Decisions Efficiently
Users need to decide how to spend their available time without feeling overwhelmed by too many options.

## UN-04 — Remember Interesting Activities
Users need to save and revisit activities they previously found interesting.

## Validation Status
These user needs are based on initial product assumptions and have not yet been validated through user interviews.
