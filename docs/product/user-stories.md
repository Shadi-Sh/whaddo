# Whaddo? — User Stories

**Status:** Draft — Not yet validated with users  
**Version:** 0.1

## US-01 — Available Time

**As a** Whaddo? user,  
**I want** to specify how much free time I have,  
**so that** I can receive activity recommendations that fit my schedule.

**Related requirements:** FR-02, FR-05

## US-02 — Location

**As a** Whaddo? user,  
**I want** to specify my current location or environment,  
**so that** I can receive activity recommendations suitable for my surroundings.

**Related requirements:** FR-03, FR-05

## US-03 — Save for Later

**As a** Whaddo? user,  
**I want** to save activities that interest me,  
**so that** I can revisit them when I have time.

**Related requirements:** FR-08

**Interaction decision:** Swiping right on an activity card saves it for later. Swipe gestures are not mandatory for the initial MVP.

## US-04 — Group Activities

**As a** Whaddo? user,  
**I want** to specify how many people are participating,  
**so that** I can receive activity recommendations suitable for our group.

**Related requirements:** To be defined when group-size support is specified.

## Notes

- These stories describe candidate capabilities and require further refinement.
- Acceptance criteria will be added before implementation.
- Group-size support is currently classified as Could Have.
- Saving activities is classified as Should Have for the initial MVP.
- User stories may be split into smaller implementation tasks as development progresses.
