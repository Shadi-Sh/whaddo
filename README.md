# whaddo

An activity discovery app for finding things to do based on your time, location, and available resources.

## Status

Whaddo? is in early product discovery. The description above is the original product idea, not a delivered capability. This repository contains discovery documentation; it has no application code or runnable product yet.

The [problem statement](docs/problem-statement.md) records approved wording. Its claims remain **unvalidated assumptions**; no user-research evidence is documented here yet. Product vision, requirements, and MVP scope remain to be developed.

## How we work

Shadi authors the product vision and future requirements. Mentor and AI feedback should help improve her drafts and make evidence gaps visible.

Use an issue to describe a task and its completion criteria. Propose document changes on a separate branch, then open a pull request for review before merging into `main`. Keep assumptions separate from research findings and record the reasons for product decisions.
